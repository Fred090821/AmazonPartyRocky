# Daily Task Scheduler with PartyRock ☁️

## Project Overview
This project demonstrates how to build a Daily Task Scheduler Application using AWS PartyRock, a generative AI platform from AWS.  

The goal of this project is to enhance productivity and organization by helping users generate optimized schedules, motivational quotes, and visual inspiration — all without writing any code.  

---

## Steps to Build
1. Generate the daily task scheduler application on PartyRock.  
2. Modify existing widgets to fit your needs.  
3. Add new widgets (motivational quotes, images, schedule optimizer).  
4. Publish your app and share it with others.  

---

## Services Used
- AWS PartyRock  

---

## Estimated Time & Cost
- Time: 15–20 minutes  
- Cost: Free (AWS currently offers PartyRock with a free trial)

## How to Use
1. Open the PartyRock platform.  
2. Enter your tasks and the time required for each.  
3. The app will automatically generate:
   - A daily schedule  
   - A motivational quote  
   - A motivational image  
   - An optimized plan with AI assistance  

---

## Key Features
- AI-generated task scheduling  
- Automatic time optimization  
- Built-in motivation (quotes + visuals)  
- No coding required
